# BOUND OS — Financial Comparison & Infrastructure Cost Analysis

> **Executive Financial Blueprint: Active Primary Cloud API Stack (~$1,269 / month) vs. In-House Options**

---

## Executive Summary

This document provides a comprehensive financial evaluation of **BOUND OS** operating on our **Active Primary Production Stack** powered by commercial Cloud APIs (Deepgram Nova-2 STT, Gemini 1.5 Flash LLM & Multimodal OCR, Azure Standard TTS, Hetzner Cloud CPX VPS & Managed PostgreSQL) at **~$1,269.00 / month total cost**.

Based on current operational baseline metrics (`Bound OS Prototype.dc.html`), **BOUND OS** generates **$84,320.00 Net MRR** across **1,214 active stores** in Côte d'Ivoire, Senegal, and Bangladesh. 

Operating on this active primary stack yields an outstanding **97.2% gross margin** ($83,051.00 net monthly profit), while eliminating GPU server hardware management overhead. Secondary self-hosted bare-metal GPU options ($99 - $194.50/mo flat) are maintained as configurable enterprise alternatives.
